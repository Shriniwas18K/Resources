# How AIML ecosystem works

The main player is Data Scientist.
1) he takes data, cleans it, feature engineers it 
2) he and data analyst sit together and peform extensive hypothesis testing based on extensive domain knowledge and grab insights trends from it, and then analyst goes for storytelling with dashboards tableu etc, and data scientist heads on for ML modelling.
3) data scientist decides statement as regression, classification, clustering, or which kind ML it is.

The sub player is ML engineer.
1) he can suggest best ML model for the scenario where data is given and all relationships have been identified already by data scientist.
2) ML engineer builds model, evaluates it, manages its lifecycle or MLOps, serves it by FastAPI.

The sub player next is data engineer
1) manages and builds platforms where above two players perform there ops
2) performs ETL, data lakes management, and builds entire infrastructure for both above.

These all above get eliminated if Deep Learning is used, because there is no selecting features, analysing trends, and without any transperancy model is built just by using high amount of computation and big data. Thus no one can identify why model is behaving like this or that. Hence companies dont prefer to use it because it doesnt gurantee any result, nor transperancy. But it is preferred is case of specific problems like LLMs,CNNs still its niche, because again no gurantee of anything in DL.

GenAI/Agentic AI is software development that is overhyped, involves CRUD using vector databases and backend servers for LLMs, chatbot UI frontend.

Computer vision is maths and entire diffirent sector of AI, uses DL CNNs etc, its niche still.

Soft computing and Optimisation is in embedded systems and advanced research specialists only, for like too niche than above too and for experienced people only.

In above ML engineer and data engineer and GenAI is open to freshers currently.
