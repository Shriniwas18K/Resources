# what is AI

AI is basically customisation service given to existing software products, where intelligence and problem solving is modelled using algorithms. In existing software products we have many types which expose there customisation and automation of redudant procedures in usage by APIs in languages like Salesforce CRM gives in Java, Ansys Mechanical Simulation gives in Python DPF C++, Solidworks 360 CAD gives in C++, PTC Windchill PLM gives in Java. The business needs of customers are many-many where each cannot be addressed by the makers considering less amount of revenue from the customers or niche use case of customer like someone small firm using Mechanical says they want AWS cloud integration into Mechanical to save there simulation results and models securely, in that case Ansys wont add this feature into Mechanical because the customer is small and its use case is niche. The small firm needs to extract the data using Python APIs given by Mechanical and send it to AWS S3. This customisation/automation is called AI.

Existing software products are key part of users lives and business processes dependent on them, and once user gets used to some product then they wont easily change because they need migrate their existing data to new one, learn the new one, invest their time and people into this learning process where the production which generates them revenue slows done because people who worked were busy learning new things. Hence people who know Ansys Mechanical will always stay on it, unless very good features are provided by similar PTC Simulate. People usually resist the change is key.

For this customisation the AI Engineer there needs to know the way to use the software product already, like someone automating CRM needs to know entire flow of CRM from marketing campaign to opportunity to lead conversion to service cloud, then only the person can customise or automate the CRM processes. Agentic AI i.e,. LLMs doing tool calling based business logic, and workflows build using langchain langgraph can be used for the same. Python stays the key language as from big companies to open source everyone uses Python for exposing their product APIs, to powerful scientific libs like tensorflow, pandas for data analysis deep learning, to using like glue language i.e. to shift data from AWS S3 to on premises, or scripting deploymeny workflows in devops. Python is used everywhere allowing to integrate anything from LLMs to devops to website to external APIs to ML DL to software products APIs. Mainly the AI Engineer needs to be knowledged at basic level that how things work in each of them with hands on experience like in web there are approaches like all logic on server and template based server side rendering like Spring MVC, all logic on client side using frontend framework like React and some using aws lambda functions, or hybrid where frontend and backend deployed seperately communicating using REST APIs.

Another approach of AI is about machine learning deep learning methodoligies and one about soft computing genetic alogrithms and one about algorithms like best first search. These are more catered towards phd scholars and researchers only. The software and computer engineers are more towards using the things built using them, like AutoML. People leading companies are looking for automating things, save time and invest resources(employees) into something that generates more revenue for the company addressing thier customers. They are not concerned with what researchers do sitting in harvard taking phds in AI.
